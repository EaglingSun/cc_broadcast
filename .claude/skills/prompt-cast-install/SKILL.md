# 프롬프트 방송 받는 쪽 설치

이 저장소의 `setup/prompt-cast/` 에 든 받는 mod(`prompt-cast-recv`)를 이 PC 의 Claude Code 에 사용자 범위로 설치한다. 설치하면 이 저장소뿐 아니라 다른 실습 저장소 창에서도 방송을 받는다. mod 는 이 폴더에서 바로 읽힌다.

설치가 됐는지는 `setup/prompt-cast/install.py` 가 판정한다(등록 · 설치 · 켜짐 · 읽는 폴더 · mod 응답). 너는 스크립트를 돌리고 결과를 그대로 전한다. 말로 「된 것 같다」고 판단하면 수강생마다 결과가 달라지기 때문이다.

## 절차

1. 저장소 루트에서 실행할 명령을 수강생에게 보여 주고 승인받는다: `python setup/prompt-cast/install.py`. 이 명령은 Claude Code 사용자 설정에 marketplace `sure-lab-cast` 를 등록하고 plugin 하나를 설치한다고 함께 알린다. 명령은 이 한 줄 그대로 실행한다 — 앞에 환경 변수를 붙이거나 뒤에 다른 명령을 잇지 않는다. 스크립트가 UTF-8 출력을 스스로 맞추고 종료 코드를 내므로 덧붙일 것이 없고, 덧붙이면 승인 창만 더 뜬다.
2. 실행하고 종료 코드와 출력 표를 읽는다.
   - **0**: 표를 그대로 보여 주고, 아래 「끝난 뒤 알릴 것」을 전한다.
   - **3**: 같은 이름이 다른 폴더로 등록돼 있다(예: 예전에 클론한 폴더). 출력에 나온 옛 경로를 보여 주고, 옛 등록과 그 plugin 을 지우고 이 폴더로 다시 등록해도 되는지 묻는다. 승인하면 `python setup/prompt-cast/install.py --replace` 를 실행하고 2 를 다시 읽는다. 승인하지 않으면 멈춘다.
   - **2**: claude 명령이 없거나 버전이 낮다. 출력의 해결 명령(`claude update` 등)을 보여 주고 승인받은 뒤 실행한다. 그다음 새 터미널에서 1 부터 다시 한다.
   - **1**: 실패 줄과 출력 전문을 그대로 보고하고 멈춘다. 다른 설치 방법을 조용히 시도하지 않는다.
3. 종료 코드가 0 이 아니면 「설치됐다」고 말하지 않는다.

## 끝난 뒤 알릴 것

- 설치 전에 열어 둔 Claude 창(지금 이 창 포함)은 새 mod 를 모른다. 그 창에서 `/reload-plugins` 를 치거나 새 창을 연다. 슬래시 명령은 수강생이 직접 친다.
- 강의 시작 때 강사 화면에 뜨는 `/cast-connect 강사IP:8790` 줄을 그대로 입력한다. 방송이 오면 입력창에 초안으로 들어오고, 고친 뒤 직접 Enter 를 친다. 입력창에 쓰던 글이 있으면 덮지 않고 입력창 위에 「도착 [넣기]」로 남는다.
- 이 저장소 폴더를 지우거나 옮기면 mod 가 깨진다. 새 위치에서 이 스킬을 다시 실행한다(3 이 나오면 위 절차대로).

## 설치는 됐는데 방송이 안 들어올 때

스크립트가 0 이면 설치는 정상이다. 그다음은 연결 문제다.

1. 수강생이 `/cast-connect`(주소 없이)를 쳐서 상태를 본다. 하단 상태줄 「📡 강사 연결 안 됨 · 주소」도 같은 뜻이다. 막 연 창은 첫 확인 전 2초쯤 「확인 중」으로 보이니 잠시 뒤 다시 본다.
2. 주소가 강사 화면의 줄과 글자 하나까지 같은지 본다. 강사 IP 는 날마다 바뀔 수 있다.
3. 같아도 안 되면 네트워크(교육장 Wi-Fi · 방화벽) 문제다. 강사에게 그대로 알린다. 주소를 추측해서 바꿔 넣지 않는다.

## 이 스킬이 하지 않는 것

- 보내는 쪽(강사용 mod · 중계 서버)은 이 저장소에 없다. 설치하지 않는다.
- 사용자 설정 파일(`~/.claude/settings.json` 등)을 직접 고치지 않는다. 등록 · 설치는 스크립트가 `claude plugin` 명령으로만 한다.
